# Freight Spot Rate Prediction & Pipeline Evaluation

An end-to-end Machine Learning pipeline developed for the Spotter Machine Learning Engineer Assessment. This repository contains data cleaning, spatial and temporal feature engineering, model training using LightGBM, validation evaluation, and prediction generation scripts.

---

## 📌 Executive Summary & Key Findings

* **Target Skewness:** The target variable (`posted_rate`) exhibits extreme right-skewness (ranging from $57.22 to $25,533.00, median $2,030.76). Models were trained on log-transformed values (`log1p`) to mitigate loss function over-indexing on high-rate outliers.
* **Data Quality Anomalies:** Identified negative weight entries (e.g., `-47,500 lbs`) and missing values across `weight` and `market_index`. Corrupt records were filtered and imputations were applied.
* **Feature Drivers:** Trip distance (`haversine_dist` / recorded distance) serves as the primary linear driver of rate ($r = 0.95$). Secondary signals include market condition indicators (`market_index`, `quote_signal`) and engineered route metrics (`weight_per_mile`).
* **Validation Strategy:** Evaluated using a 5-fold cross-validation scheme to prevent data leakage and ensure generalized performance across temporal and geographic splits.

## ⚙️ Installation & Setup

1. Clone the Repository:
```bash
git clone [https://github.com/zhoyaginez/freight-rate-prediction.git](https://github.com/zhoyaginez/freight-rate-prediction.git)
cd freight-rate-prediction
```
2. Set Up Environment & Install Dependencies:
```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r requirements.txt
```

---

## 🚀 How to Run & Validate

1. Execute the Pipeline
Open Ena_Spotter_Assessment.ipynb in Google Colab or Jupyter Notebook and run all cells. This will clean the data, train the LightGBM model, save the serialized artifact to models/, and output predictions.
2. Run Official Validation
Execute the provided validator script from your terminal to verify prediction formatting and generate the December evaluation chart:
```bash
python score.py \
  --predictions validation_predictions.csv \
  --december-predictions data/december_chart_inputs.csv \
  --output-dir scorer_results
```
Expected Output:
```text
Validated 12,000 final predictions.
Validated 31 fixed December predictions.
Created chart: scorer_results/candidate_december.png
Final validation metrics are calculated by Spotter after submission.
```
